# 图纸识别（扫描）功能设计

日期：2026-08-31（2026-09-01 按“网格=对齐参考、最终尺寸自动”重构，本文档为最终版）
状态：已与用户确认（固定网格+移图 · 黑标背景置空 · 自动网格识别 · 最终尺寸自动）

## 目标

用户导入一张已有拼豆图纸（截图 / 拍照），**不调用 AI**，纯本地识别为方形色号网格，
随后进入现有展示 / 修改 / 智能拼豆 / 导出流程。作为第二大功能，入口在首页显眼位置。

## 交互：固定网格（对齐参考）+ 移图

- 屏幕固定一张**正方形**网格，格数由用户调节（**滑块 +/−**，默认 10，范围 5~50，
  **不提供输入**）。网格只作对齐参考，位置锁死，改格数只影响显示密度。
- 用户缩放（双指）/ 拖动（单指）**图片**让图纸色块对齐网格线——网格不动，图动。
- 初始「对齐图片整体」：整图按 contain 铺进网格矩形；自动对齐（投影法）成功后对齐到图纸中间区域。
- 微调：◀▶▲▼ 按 1/10 格平移图片（作用在图和网格的关系上）；「自动对齐」「重置对齐」按钮。
- 手势只作用于图片；canvas `touchmove` 用 `catch` 防止拖动滑出页面触发返回。

## 识别管线

```
导入图纸图 → 调网格格数（对齐参考）→ 缩放/拖动图片对齐（自动对齐预置）
→ 按校准格宽从网格原点扫遍整图 → 逐格主色+中心黑标占比
→ 背景判定 → 取“有颜色区域”长宽最大值生成正方形图纸 → postProcessGrid
→ globalData.pattern(mode:'scan') → 展示/修改/智能拼豆/导出复用
```

1. **读图**：工作图等比缩放到 ≤2048。
2. **对齐后计算**：一格大小 `cellPx = 网格格边长 / view.scale`（图片像素）；
   原点 = 网格 (0,0) 映射回图片的坐标。
3. **扫全图** `scanAtPitch`：按 `cellPx` 从原点扫遍整图，每格取主色 + 中心黑标占比。
4. **背景判定** `buildBgMask` → **最终图纸** `finalizePattern`：取“有颜色区域”（非背景）
   包围盒长宽最大值，生成正方形图纸（彩色内容放左上，其余补背景；包围盒内背景洞保留；
   全部为背景则失败）。
5. **后处理** `postProcessGrid`（跳过背景格）。
6. **落数据**：

```js
globalData.pattern = {
  grid, size, // size = 彩色区域长宽最大值，自动确定，非用户指定
  set, imagePath,
  mode: 'scan', style: '图纸识别',
  bgMask // true=背景(置空，不标号/不计颗数/导出空白)
}
```

## 黑标判定（sampleCell）

- 中心区域 = 格子中心 60%（避开四边网格线）。
- “黑标”像素 = 亮度 < 128 **且**低饱和（max−min ≤ 64）——纯黑印字是灰黑，彩色填充不算。
- 中心黑像素占比 ≥ 1% 视为“有标号”。

## 网格线检测（detectGridLines）

- 降采样到 ≤512，f×f 块“任一像素暗即暗”（max-pooling 保细线）。
- 竖直 / 水平投影：只取图像中间 50% 区域，统计每列 / 每行暗像素量；超过带高 35% 为候选线；
  按线宽 ≤4 过滤深色色块列；候选线拟合成均匀晶格（中位间距 = 格宽，最左 / 最上晶格线 = 原点）。
- 原点回退：第一条线左侧若“有内容”（非近白）→ 前面还藏着一列，原点再退一个格宽
  （解决最左列无外框线时整体偏移一格）。
- 限制：要求网格线清晰可见；旋转 / 透视会失败 → 手动对齐兜底。

## 误差处理

- 对齐层：固定网格不漂移；自动检测精确算 pitch / origin；手动缩放拖动 + 1/10 格微调兜底。
- 采样层：主色桶抗网格线 / 抗锯齿；黑标判定只看中心区域。
- 最终尺寸：按彩色区域包围盒自动裁掉边距；不足正方形时补背景。
- 旋转 / 透视：不做，导入阶段提示截图或拍正。

## 内容安全

识别为纯本地处理，MVP 不调 `sec-check`；后续入库图库再补 `imgSecCheck`。
