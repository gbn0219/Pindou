# 图纸识别（扫描）功能设计

日期：2026-08-31（交互与背景于 2026-09-01 重构，本文档为最终版）
状态：已与用户确认（固定网格 + 移图 · 黑标背景置空 · 自动网格识别）

## 目标

用户导入一张已有拼豆图纸（截图 / 拍照），**不调用 AI**，纯本地识别为 R×C 色号网格，
随后进入现有展示 / 修改 / 智能拼豆 / 导出流程。作为第二大功能，入口在首页显眼位置。

## 交互：固定网格 + 移图

- 屏幕上固定一张 R×C 网格（位置锁死、不能拖），居中铺在画布、四边留白 `FIT_PAD=16`。
- 改行 / 列数 → 网格密度变化；方形 MVP（宽 == 高）。
- 用户缩放（双指）/ 拖动（单指）**图片**去对齐网格——网格不动，图动。
- 初始「对齐图片整体」：整张图按 contain 铺进网格矩形。
- 自动对齐：`detectGridLines` 投影峰值法检测格宽 / 格高 / 原点；成功后把图片缩放到
  “1 格 = 1 网格格”并平移到网格，即对齐图纸中间区域；失败则保持整图预览，手动对齐兜底。
- 微调：◀▶▲▼ 按 1/10 格平移图片（作用在图和网格的关系上）；无“宽窄 / 高矮”按钮；
  「自动对齐」「重置对齐」按钮。
- 手势只作用于图片；canvas `touchmove` 用 `catch` 防止拖动滑出页面触发返回。

## 识别管线

```
导入图纸图 → 输入 宽(列)×高(行) → 固定网格 + 移图对齐（自动对齐预置）→ 识别
→ 逐格主色 + 中心黑标占比 → CIELAB 最近色映射色号 → 黑标背景置空 → postProcessGrid
→ globalData.pattern(mode:'scan') → 展示/修改/智能拼豆/导出复用
```

1. **读图**：工作图等比缩放到 ≤2048。
2. **固定网格采样** `scanScreenGrid`：每格映射回图片区域，`sampleCell` 取主色 + 中心黑标占比。
3. **映射** `rgbGridToCodes`：CIELAB 最近色 → 所选色系色号（默认 221）。
4. **背景置空** `buildBgMask`：白格中心有黑标 → 白豆（一般 H2）；无黑标 → 背景（置空）；
   整图无任何黑标 → 全当白豆（兜底）；页面有「背景自动识别 / 全当白豆」开关。
5. **后处理** `postProcessGrid`（跳过背景格）。
6. **落数据**：

```js
globalData.pattern = {
  grid, size: rows, set, imagePath,
  mode: 'scan', style: '图纸识别',
  bgMask // true=背景(置空，不标号/不计颗数/导出空白)
}
```

## 黑标判定（sampleCell）

- 中心区域 = 格子中心 60%（避开四边网格线）。
- “黑标”像素 = 亮度 < 128 **且**低饱和（max−min ≤ 64）——纯黑印字是灰黑，彩色填充不算。
- 中心黑像素占比 ≥ 1% 视为“有标号”。

## 网格线检测（detectGridLines）

- 降采样到 ≤512，f×f 块“任一像素暗即暗”（max-pooling 保细线）。
- 竖直 / 水平投影：只取图像中间 50% 区域，统计每列 / 每行暗像素量；超过带高 35% 为候选线；
  按线宽 ≤4 过滤深色色块列；候选线拟合成均匀晶格（中位间距 = 格宽，最左 / 最上晶格线 = 原点）。
- 原点回退：第一条线左侧若“有内容”（非近白）→ 前面还藏着一列，原点再退一个格宽
  （解决最左列无外框线时整体偏移一格）。
- 限制：要求网格线清晰可见；旋转 / 透视会失败 → 手动对齐兜底。

## 误差处理

- 采样层：主色桶抗网格线 / 抗锯齿；黑标判定只看中心区域。
- 对齐层：固定网格不漂移；自动检测精确算 pitch / origin；手动缩放拖动 + 1/10 格微调兜底。
- 旋转 / 透视：不做，导入阶段提示截图或拍正。

## 内容安全

识别为纯本地处理，MVP 不调 `sec-check`；后续入库图库再补 `imgSecCheck`。
