# 拼豆标准色彩 RGB 与拼豆盘尺寸规格

> 调研日期：2026-08-03（Asia/Shanghai）
> 用途：拼豆图纸生成微信小程序 —— 主界面 48/72/144/221 色选项、像素化转标准色、图纸展示与修改。

## 1. 结论速览

- **国内默认标准色卡：MARD（Mard）221 色**，2.6mm 小豆/融合豆，多个工具站与售卖页将其作为默认参考体系。
- **48/72/144/221 色 = 套装可调用的色号范围**，不是图纸尺寸，也不要求把套装颜色全部用上。
- 标准豆径：**Midi 5mm 为行业默认**（95% 图纸按 5mm 设计）；Mini 约 2.6mm；Maxi 10mm。
- 拼豆盘（即拼豆板）大小以像素为单位：**52×52 / 78×78 / 104×104** 三档。
- 本项目默认采用 `HansBug/pindou-color-data` 的 `mard-221-alfonse-doudou` 色卡作为 RGB 基准；48/72/144 套装色号构成采用 `get-colors-from-beans` 的公开数据。

## 2. 色彩体系说明

### 2.1 常见品牌

| 品牌 | 说明 | 常见规格 |
| --- | --- | --- |
| MARD（马德） | 国内最主流，玩家默认参考 | 24/48/72/96/120/144/168/221/264/291 色 |
| COCO | 常见性价比品牌 | 291 色等（需转色号） |
| 漫漫家 / 盼盼家 / 咪小窝 | 工具生态常见品牌 | 278/289/290 色等 |
| 优肯（Artkal 官方） | 官方体系，含 MARD 兼容的 M221 | 174/197/221/418 色 |
| 黄豆豆 / DODO / 小舞 | 与 MARD 291 数据基本同源 | 291 色 |
| Perler / Hama（国际） | 欧美主流 | Perler 103 色、Hama Midi 92 色 |

### 2.2 “48/72/144/221 色”的含义

“24 色、48 色、72 色、96 色、120 色、168 色、221 色”说的是**可调用的色号范围**，不是图纸尺寸，也不是必须全部使用完（来源：拼豆色号入门公众号文章）。套装是递进关系：48 色 ⊂ 72 色 ⊂ 144 色 ⊂ 221 色（色号范围逐级扩大，具体构成见第 4 节）。

### 2.3 RGB 值可靠性说明

- 拼豆厂商**不公开官方 RGB**；下表数值来自社区整理（工具站/玩家人工标注/官方色卡图采样）。
- 实物豆色受**批次、屏幕、光线**影响，RGB 仅用于“最近色匹配”的近似参考；不同公开来源之间也存在少量 HEX 差异（例如 MARD 221 两个公开来源有 77 个色号 HEX 不同）。
- 开发时建议把色卡数据抽成独立 JSON 文件，便于后续按实物色卡校正。

## 6. 拼豆盘（拼豆板）尺寸规格（以像素为单位）

- 拼豆盘（即拼豆板）大小以像素为单位，共三个型号：**52×52、78×78、104×104**。
- 生成图纸时按所选型号输出对应像素网格（52×52 = 2704 格、78×78 = 6084 格、104×104 = 10816 格），1 格 = 1 颗拼豆。

## 8. 开发落地建议

1. 将第 3 节 221 色表与第 4 节套装清单转成 `colors.json`（含 code/hex/rgb），作为小程序静态数据。
2. 像素化后做**最近色匹配**（建议 CIELAB 或加权 RGB 距离），并限制只输出当前所选套装内的色号。
3. 图纸导出与修改页的取色面板，按第 4 节套装清单渲染“小盒子陈列”式的色板。
4. 拼豆盘大小参数（52×52 / 78×78 / 104×104 像素）同时用于图纸网格尺寸选项与导出说明。
