### 2026-09-16 · 跟拼四周行列号环（厚一格、逐格标绝对行号）

- **需求**：全屏跟拼（点颜色高亮所在格子那页）四周的行列号要能看出"当前显示的是第几行到第几行、第几列到第几列"，缩小时不合并，哪怕编号只剩几个像素也要显示，形如"在显示的图纸四边各加一圈与图纸格同尺寸的灰格，格里写行列号"。
- **`utils/pattern.js`**：原 `renderRulers`（固定在画布四边、带厚 16~56px、按 `rulerStep`/`rulerPace` 每 N 格才标一个）重写为**编号格环**——四边各贴一条与图纸格同尺寸（厚 = 一格屏幕边长 `(cell+GAP)×scale`）的浅灰带，逐格写该行/该列的绝对序号，随缩放/拖动实时反映当前可视行列，**任何缩放级别都逐格标号、不合并**（字号下限 4px）；每格屏幕边长 < `RULER_DIVIDER_MIN`(6px) 时省略逐格线，避免缩小时灰带糊成一片。删除 `rulerMetrics` / `rulerStep` / `rulerPace` / `RULER_BAND_MIN|MAX` / `RULER_MAX_LABELS` / `RULER_STEPS` / 交互页暖米色常量。
- **初始视图**：`rulerFitView(total, cellPx, gap, areaW)` 改为「图纸 + 四边各一圈编号格」正好铺满画布宽度（`scale = areaW / (total + 2×pitch)`，`ox = oy = pitch×scale`），进入跟拼时图纸紧贴编号环内侧；展示页/修改页两处调用同步传 `pattern.GAP`。
- **验证**：`tests/pattern.test.js` 重写编号环用例（带厚 = 一格、铺满几何、平移后只标可视行列 3~4、极小缩放下仍逐格标全部行号/列号且不画格线、编号带固定不动、网格移出屏幕时无编号），`node tests/*.test.js` 全绿；另用无头 Edge 渲染 `ruler-preview/preview.html` 做像素级核对（编号环底色/带厚/逐格墨迹）。
- **已知**：编号环贴画布四边，全屏底部色板浮层会盖住下边那条（与改动前一致，仅上/左/右常显）。

### 2026-09-01 · 图纸识别重构：固定网格 + 移图 + 自动对齐 + 背景置空（commit `6a6b75a`）

**重构校准与背景（替代 08-31 初始版“拖框圈选 + 白格全算”）**
- 入口不变：首页 hero 下方「识别已有图纸」→ `page/scan/index`（第 8 页，不调用 AI）
- 交互：屏幕固定一张**正方形**网格，格数用**滑块 +/−** 调（默认 10，范围 5~50，不提供输入），仅作对齐参考；用户缩放/拖动**图片**对齐网格；◀▶▲▼ 为 1/10 格平移图片；新增「自动对齐」「重置对齐」
- 自动对齐：`scan.detectGridLines` 投影峰值法检测格宽/格高/原点；初始整图铺进网格，识别成功自动对齐到图纸中间区域；失败/不准可手动缩放拖动
