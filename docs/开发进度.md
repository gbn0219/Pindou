## 最近里程碑

### 2026-08-31 · 界面统一与全屏拼豆优化（commit `20b2a7f`）

**界面一致性**
- 统一暖纸配色/卡片表面/选中态：黄=主按钮、墨=选中、红=强调/危险；补齐未定义 CSS 变量（`--color-card`、`--color-bead-hi`、`--color-cast-strong`、`--color-shadow-inset`）；清掉乱入的蓝色。

**图纸展示 / 修改**
- 画布显示区改 **1:1 正方形**，去掉四周坐标刻度条，居中画板；收紧画布卡内边距。
- 修复预览页**非全屏下双指缩放失效**（`onTouchMove` 非全屏分支为空，之前加"全屏"时漏掉）。

**全屏拼豆（pattern / pattern-edit 共用）**
- 去掉坐标条，网格铺满画布；底部面板占满剩余高度，色卡一行 **3 个、等宽、内容居左**；**多行色卡**铺满。
- 新增**网格选项**：网格线开关 + 密度（默认每 5 格，可切每 10 / 每 20）——目前只加在预览页全屏（修改页未渲染网格线）。
- **一键跟拼改为两步撤回**：点已拼完的颜色只是设为当前色、按钮变"撤回"；点"撤回"才真正取消；再点当前色取消选中。

**其他**
- 修复编辑页"放大键"点击无响应（去掉放大键上多余的 `catchtouchstart="noop"`）。
- `app.js` 加 `onPageNotFound` 路由兜底（空路由回首页，避免硬报错）。
- 新增 `utils/beading.js`、`styles/beading.wxss`、`tests/beading.test.js`。

**注意**：本轮的"大胆重设计（Bead Atelier 主页 + 配色 A/B）"已出方案/预览图，用户选择了 A 并短暂实现后**已撤回**，主页回到暖纸版。若后续要做，按 `docs/page-redesign-plan.md` 与 `miniprogram/styles/tokens.wxss` 为准。
